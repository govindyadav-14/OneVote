# OneVote

Welcome to OneVote, a modern and secure digital voting application built with React and Node.js!

## Features
- Secure user authentication and JWT-based sessions.
- Real-time voting dashboard.
- Admin panel for managing candidates and viewing results.
- Fully responsive design.

## Getting Started

### Prerequisites
- Node.js installed on your machine.
- MongoDB installed and running locally.

### Installation

1. Navigate to the backend directory:
   ```bash
   cd backend
   npm install
   ```

2. Navigate to the frontend directory:
   ```bash
   cd frontend
   npm install
   ```

### Running the Application

1. Start the backend server (ensure MongoDB is running):
   ```bash
   cd backend
   npm run dev
   ```

2. Start the frontend development server:
   ```bash
   cd frontend
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:5173`.
